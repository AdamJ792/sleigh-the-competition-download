# Sleigh the Competition: Windows installer

This repository only hosts the Windows installer for **Sleigh the Competition**, the Christmas quiz game show for Windows 10 and 11 by [AJL Digital Studio](https://www.ajldigitalstudio.co.uk/products/sleigh-the-competition). It contains no source code.

**You need a licence to play the full game.** Buy it at https://www.ajldigitalstudio.co.uk/products/sleigh-the-competition. Your activation key is emailed to you after purchase, along with the download link. Without a key, the game runs as a demo with the free Taster Quiz.

## Download
Get the latest version from [Releases](../../releases/latest). Each release lists the installer's SHA-256 checksum in `SHA256SUMS.txt`. To check it in PowerShell:

```powershell
Get-FileHash .\SleighTheCompetition-Setup-1.0.0.exe -Algorithm SHA256
```

Windows may show "Windows protected your PC" (unknown publisher). Choose **More info → Run anyway** only if you downloaded the file from this page or from the link in your order email.
